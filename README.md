One line, 1 to 240 characters, that gives the judge a quiet, earned moment of pride for someone in a scene: a small person doing something hard, a long effort finally landing.

## The line

> At seventy-three, after three years of evening classes, Mr. Okafor read his granddaughter's birthday card aloud, every word, without asking for help once.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set for a local test run).
